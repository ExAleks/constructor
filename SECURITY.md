# Политика безопасности

## Что делает проект

`Lucky Constructor` — визуальный конструктор inline-клавиатур для Telegram-ботов.
Это статическая страница (`index.html` + `constructor-ui.js`), которая работает
в браузере и не имеет серверной части: состояние хранится в `localStorage`,
готовый JSON пользователь копирует в своего бота.

## Поддерживаемые версии

Поддерживается ветка `main`.

## Что считается уязвимостью

В области действия:

- XSS через импортированный JSON, названия кнопок, URL или данные из
  `localStorage` (сейчас часть отрисовки идёт через `innerHTML`);
- подстановка `javascript:` и подобных схем в поля URL/Web App;
- утечка содержимого конструктора на сторонние домены (сейчас внешних
  запросов нет, кроме CDN SortableJS);
- подмена CDN-скрипта без проверки целостности.

Вне области действия:

- последствия публикации конструктора на чужом сервере;
- уязвимости Telegram Bot API и браузера;
- социальная инженерия.

## Как сообщить

Не открывайте публичный issue. Используйте приватный канал GitHub:

1. Вкладка **Security** → **Report a vulnerability** (GitHub Security Advisories).
2. Укажите браузер и версию, шаги воспроизведения, ожидаемое и фактическое
   поведение, оценку влияния.

Подтверждаем получение в течение 7 дней, исправление стараемся выпустить в
течение 30 дней. Bug bounty нет.
